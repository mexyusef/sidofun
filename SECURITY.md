# Security Policy

If you believe you have found a security issue in Sidofun, do not open a
public issue first.

Please report it privately through GitHub security advisories for:

- `https://github.com/mexyusef/sidofun`

If GitHub private reporting is unavailable, contact the maintainer directly
through the repository profile and include:

- a clear description of the issue
- reproduction steps
- impact assessment
- any suggested mitigation

Security reports will be reviewed as quickly as practical. Please avoid public
disclosure until the issue has been assessed and a fix or mitigation is ready.
